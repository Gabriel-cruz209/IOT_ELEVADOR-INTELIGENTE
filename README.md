
# Elevador Inteligente — Grupo 8

Projeto acadêmico desenvolvido na disciplina de **IoT 9**, com foco no desenvolvimento de um protótipo de **Elevador Inteligente utilizando Arduino UNO**.

## Sobre o Projeto

O sistema tem como finalidade simular o funcionamento automatizado de um elevador de três andares, permitindo a seleção de destinos, indicação do andar atual e do movimento, além do controle da porta e do tratamento de situações específicas.

A solução utiliza uma **máquina de estados** para organizar os diferentes modos e etapas de funcionamento do sistema, garantindo o tratamento adequado dos comandos e evitando operações incompatíveis.

## Funcionalidades

* Controle de três andares;
* Seleção do andar de destino;
* Indicação do andar atual;
* Indicação de movimento;
* Controle da porta;
* Simulação de excesso de carga;
* Modo de manutenção;
* Sistema de emergência;
* Tratamento de comandos incompatíveis;
* Gerenciamento de múltiplas chamadas.

## Tecnologias e Componentes

* **Arduino UNO**
* Teclado
* Display
* Servo ou motor 5 Vcc
* LEDs
* Buzzer
* Botões
* Sensor ultrassônico
* Display de 7 segmentos
* Protoboard e jumpers

## Desenvolvimento

O projeto contempla as etapas de análise, projeto, montagem do hardware, desenvolvimento do software, integração e validação. Durante o desenvolvimento, são realizados testes individuais dos componentes e testes de integração para verificar o funcionamento completo da solução.

## Objetivo

Aplicar conceitos de **Internet das Coisas (IoT), sistemas embarcados, automação e programação**, desenvolvendo uma solução capaz de representar o funcionamento de um elevador automatizado e seu tratamento de diferentes condições de operação.
